# SOP — Harsh Driving Event Review and Escalation

**Owner:** Jason Cartledge **Runs:** every Monday, 15 minutes
**Applies to:** every vehicle on Fleeta Cloud

The point of this SOP is that nobody ever again gets a nasty surprise from six
weeks of stored footage. Events get looked at weekly, drivers get told early,
and coaching happens before it becomes a disciplinary problem.

---

## 1. Weekly review (Monday, 15 min)

1. Open Fleeta Cloud → Events → filter to the previous 7 days, all vehicles.
2. Record per driver in the Fleet Scorecard: total events, and a breakdown of
   Impact / Hard Braking / Hard Acceleration / Hard Cornering.
3. Divide each driver's total by kilometres driven that week to get
   **events per 100 km**. Raw counts punish whoever had the long motorway run —
   the rate is the number that actually compares people.
4. Open any **Impact** event, always. Impacts are never left unopened.
5. Apply the escalation table below.
6. Note the outcome against the driver's name. One line is enough.

## 2. Thresholds

Tune these after four weeks of real data — start here.

| Rate (events / 100 km) | Band | Action |
|---|---|---|
| 0 – 2.0 | Green | Nothing. Note it. |
| 2.1 – 4.0 | Amber | Informal chat this week. "Saw a few hard stops Tuesday — anything going on?" |
| 4.1 – 7.0 | Red | Formal coaching session within 5 days. Review 3 clips together. Written file note. |
| 7.0+ | Critical | Coaching within 48 hours, plus 2 weeks of daily monitoring. |

**Straight to Critical regardless of rate:**

- Any **Driving Impact** event
- Any event over the posted speed limit by 15 km/h or more
- Any event with an unauthorised passenger visible
- Any cluster of 5+ events inside 30 minutes
- Any event where the footage shows deliberate aggressive driving

## 3. Coaching session — how to run it

Not a disciplinary meeting. Do not make it one, or drivers start hiding things.

1. Sit down with the driver. Screen on, clips queued.
2. Play the clip. Ask them what was happening. Listen first.
3. Name the specific behaviour, not the person. "This is a 60 zone and we're
   braking that hard from 78" — not "you drive like an idiot."
4. Agree one or two concrete changes. Following distance. Leaving 10 minutes
   earlier. Not taking the call.
5. Write three lines in the file: date, what was reviewed, what was agreed.
6. Re-check that driver's rate the following Monday.

**Escalate to a disciplinary process only when** the same behaviour continues
after documented coaching, or a single event is serious enough to stand on its
own (clause 2.2 of the Vehicle Policy). At that point the coaching notes become
the evidence that the driver was told and given a chance to fix it.

## 4. Alerts — set these up once

In Fleeta Cloud notification settings, send to Jason immediately:

- Any Impact event (driving or parking) → push + email, same minute
- Any vehicle moving outside 05:00–19:00 Mon–Sat, or at any time Sunday
- Any camera offline more than 4 hours during business hours
- Any SD card error or format event

Camera-offline alerting matters as much as the driving alerts. A camera that
quietly stops uploading is how you end up with nothing when you need it.

## 5. Retention — know your number

Fleeta cloud storage overwrites. **Confirm the retention period on the current
plan and write it here: ______ days.**

Anything worth keeping past that gets downloaded, hashed and filed in the week
it happens. The SD card holds continuous footage but cycles faster — assume
roughly 2–4 weeks depending on card size and driving hours, and treat it as
gone after that.

## 6. New driver induction — before they get keys

- [ ] Licence sighted, photographed, expiry diarised
- [ ] Vehicle Use and In-Vehicle Camera Policy read and signed
- [ ] Camera shown to them physically — where it is, what it records, that
      cloud upload happens on triggers
- [ ] Cabin audio status stated out loud and recorded on the signed policy
- [ ] Passenger rule explained (no unapproved passengers, ever)
- [ ] Incident procedure walked through
- [ ] First-week check: review their events Friday, coach early

## 7. Quarterly

- Re-baseline the thresholds against actual fleet data
- Re-issue the policy if the camera configuration changed at all
- Check every vehicle's camera is uploading and the SD card is healthy
- Spot-check that coaching notes are actually being written
